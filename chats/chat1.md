## User

Design a mobile app for a weight tracker. The app is intended to keep track of the weight of a group of friends. The data is read from  my google drive (name of the file is 2026 Los Zonder Pan; the names of the sheets “Peso” and “Estrategia”). You have access to that file. 
Once a week I input the new entries to the table DatoPeso, corresponding to the new weights for each participant. The app should read the data from the google drive when it is running.
For each participant, create a cool and fun avatar (ghibly studio style)
The app should present in a cool and beautiful way the following data: 
. Next to the avatar, please include
- the initial weight (include also initial BMI) (table DatoPeso, week nr 0)
- the target weight (include also target BMI) (table “Target”, Peso deseado)
- the target weight loss (table “Target”, Kilos por perder”)
- the current weight (last input in the table “Peso”) and the number of the week.
- the current BMI and whether it is normal, overweight, etc.

To calculate the BMI, use the height listed in table “Estatura”, 

Create at the bottom of the screen, three navigation buttons:
- Participant: where the participant can be selected and the data mentioned above is presented. 
- Strategy: where the strategy for each week is included. For this, use the information on Table “Estrategia”. Make clear on which week are we now. Create for each week a symbol that represents the strategy, Make the 
- Projection: estimate the weight to be expected by the end of the period (10/October). For this, use a linear regression or a more accurate data technique; Use as input the weights entered in the table DatoPeso. Create cool and colourful line diagrams for all participants, with x-axis the date, primary y-axis the expected weight (and weight loss) and secondary y-axis the expected BMI.

For each button, create a cool icon.

When the app opens, please read the data available on the google drive file.

If a new data entry is found, please sends a notification email to the participants
